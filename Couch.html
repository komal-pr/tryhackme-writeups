🟢 ROOT

🖥️ Interactive Root Shell (Bonus)

Spawn a full interactive root shell:

atena@ubuntu:~$ docker -H 127.0.0.1:2375 run -it -v /:/hostos alpine chroot /hostos /bin/bash
root@ubuntu:/# whoami
root

💡 Docker daemon listened on tcp://127.0.0.1:2375 without TLS. Mounting / into a container gives full host FS access as root.

🔬 Vulnerability Chain Summary

  • CouchDB No Auth — CouchDB exposed on port 5984 without authentication enabled
  • Plaintext Credentials — Sensitive credentials stored in plaintext in a CouchDB document
  • SSH Credential Reuse — Credentials found reused for SSH authentication
  • Docker API Exposure — Docker daemon bound to TCP on 127.0.0.1:2375 without TLS
  • Container Escape — Mount host root FS via unauthenticated Docker API

🎯 Key Takeaways

  • CouchDB should never be exposed without authentication — set require_valid_user = true
  • Docker daemon should never bind to TCP without TLS certificates
  • Defense in depth: a misconfigured Docker socket gives instant root on the host
